# Sania's Birthday Surprise

A mobile-friendly birthday page with a purple, starry, BTS-inspired aesthetic. It includes Sania's two photos and the piano-cover audio file supplied for this page.

## Files
- `index.html` — page content
- `style.css` — styling and responsive layout
- `script.js` — buttons, music controls, and sparkles
- `images/` — the two supplied photos
- `music/still-with-you-piano.mp3` — supplied audio

## Publish with GitHub Pages
1. Create a new **public** repository on GitHub.
2. Upload the contents of this folder (the files and folders inside it).
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait for GitHub Pages to publish; the site URL will appear in the Pages section.

## Customize
- Name and birthday date: edit the main heading and date in `index.html`.
- Birthday message: edit the paragraph inside the `intro-inner` section.
- Photos: replace the two files in `images/`, keeping their exact filenames.
- Song: replace `music/still-with-you-piano.mp3`, keeping the exact filename.
- The music starts only after the visitor taps the play button, because mobile browsers require a user gesture.
